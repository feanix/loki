# Contributing

Loki is developed by Astrid Winters. For now the project takes **bugs and ideas through Issues only**.

- **Found a bug?** Open an Issue. Say what you did, what you expected and what happened; attach the PNG name (the suffix matters: `_co`, `_nohq`, ...) and, if a row shows a message, copy it. If Loki crashed, `%APPDATA%\Loki\crash.log` has the details.
- **Have an idea?** Open an Issue and describe the problem you want solved.
- **Pull requests are not accepted for now.** Please open an Issue instead. This may change later; this file will say so.
