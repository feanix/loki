# Contributing

Loki is developed by Astrid Winters. For now the project takes **bugs and ideas through Issues only**.

- **Found a bug?** Open an Issue. Say what you did, what you expected and what happened; attach the PNG name (the suffix matters: `_co`, `_nohq`, ...) and, if a row shows a message, copy it. If Loki crashed, `%APPDATA%\Loki\crash.log` has the details.
- **Have an idea?** Open an Issue and describe the problem you want solved.
- **Pull requests are not accepted for now.** Please open an Issue instead. This may change later; this file will say so.

## Building

You need Python 3.12 (`pip install pillow pyinstaller`) and a stable Rust toolchain (`cargo`, MSVC target). The built-in encoder is a Rust crate (`native/paa`) built as a Python extension. `build/build_native.py` runs `cargo build --release --locked --features python` and copies the result to `src/loki/_paa.pyd`; no maturin is needed. `python build/build.py` builds the encoder, then writes `dist/Loki.exe` and the console `dist/Loki-cli.exe` (one file each; the encoder is inside, so the exe needs no Rust, Python or Arma 3 Tools on the machine). `python build/release.py` builds `dist/Loki-<version>-win64.zip` and `dist/SHA256SUMS`; the zip holds `Loki.exe`, `Loki-cli.exe`, `README.md`, `LICENSE` and `THIRD_PARTY_NOTICES`. Cargo output goes to a folder per checkout, `%LOCALAPPDATA%\Loki\cargo-target\<hash>` (or `CARGO_TARGET_DIR` if set). Running from source also needs the extension: `python build/build_native.py` once (the tests do it themselves); then run `python -m loki` (with `src` on the path). The icon is generated by `python assets/make_icon.py`. The PAA format notes behind the encoder are in [docs/PAA-FORMAT.md](docs/PAA-FORMAT.md).

## Tests

`python -m pytest -q` runs the Python tests. `cargo test --locked --manifest-path native/paa/Cargo.toml` runs the encoder tests.

## Headless use

`python -m loki --scenario FILE --settings JSON [--out LOG]` runs a script of actions and prints the state. `--screenshot OUT.png` captures the window; add `--drop FILE...` to post it a real file drop first.
